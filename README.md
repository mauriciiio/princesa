# Prontuário da Princesa

App pessoal para organizar os exames, vacinas, remédios e o peso da Princesa (Shih-Tzu).

Este repositório só tem o programa. Os dados e os PDFs ficam no Google Drive do dono,
numa pasta que só este app enxerga. Nada de pessoal fica aqui.

Endereço do app: https://mauriciiio.github.io/princesa/

Os arquivos daqui são gerados pelo `build.py` (pasta `app-celular`) e enviados pelo `publicar.py`.
Não edite à mão: a próxima publicação apaga e regrava tudo, menos este README.
